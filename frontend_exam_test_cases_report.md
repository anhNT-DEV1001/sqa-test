# Báo cáo Kết quả Unit Test - Student Exam Suite (Frontend & Backend)

Dưới đây là báo cáo tổng hợp chi tiết từng Test Case cho luồng làm bài thi của sinh viên trên cả Frontend và Backend.

## FILES THAT ARE TESTED			
			
| # | File | Module | Description |
|---|---|---|---|
| 1 | `backend/src/modules/exams/exams.student.service.ts` | students | Tested exam room join logic, data retrieval, auto/manual grading logic, and result viewing access control. |
| 2 | `frontend/src/components/organisms/FaceVerificationModal/FaceVerificationModal.tsx` | students | Tested AI distance threshold logic (0.0 - 1.0), camera error handling, and scanning UI states. |
| 3 | `frontend/src/app/(privateLayout)/dashboard/student/exams/[publicId]/take/TakeExamPage.tsx` | students | Tested exam duration countdown, question navigation, answer persistence, and auto-submission logic. |
| 4 | `frontend/src/components/molecules/JoinExamModal/JoinExamModal.tsx` | students | Tested input validation, API error handling, and exam entry navigation. |
| 5 | `frontend/src/components/molecules/CompletedExamCard/CompletedExamCard.tsx` | students | Tested score percentage calculation, pass/fail color status display. |

## Files/Modules THAT DO NOT Need Testing			
			
| # | File/Module | Module | Reason |
|---|---|---|---|
| 1 | `face-api.js` (external) | AI | External library logic is treated as a black box and mocked for unit testing. |
| 2 | Browser MediaDevices API | browser | Hardware-level APIs (camera) are mocked to ensure tests run in CI environments. |
| 3 | `frontend/src/app/(privateLayout)/dashboard/student/exams/[publicId]/result/page.tsx` | students | Primarily a display component; core status logic is tested in Backend ExamsService. |
